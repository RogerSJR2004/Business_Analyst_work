# 📊 Business Analysis Projects

Welcome to my Business Analysis repository! This space showcases hands-on projects that combine data analytics, visualization, and machine learning to deliver real-world business insights. 
Each project focuses on identifying opportunities, understanding user behavior, and supporting data-driven decision-making.

---

## 🔍 Current Projects

### 1. 🧠 Customer Segmentation

**Goal:**  
To segment customers based on key behavioral and demographic data, helping businesses personalize marketing and improve customer retention.

**Key Tasks:**  
- Data cleaning and preprocessing  
- Applied clustering algorithms (K-Means, Hierarchical Clustering)  
- Visualized segments using PCA and scatter plots  
- Delivered business insights for targeted campaigns  

**Tools Used:**  
`Python`, `Pandas`, `Scikit-learn`, `Seaborn`, `Matplotlib`

---

### 2. 💬 Sentiment Analysis

**Goal:**  
To analyze customer reviews and feedback using Natural Language Processing (NLP) to extract sentiment and uncover brand perception.

**Key Tasks:**  
- Text preprocessing (stopwords, stemming, vectorization)  
- Built sentiment classification models using Naive Bayes & Logistic Regression  
- Visualized polarity and emotion distribution  
- Extracted key sentiment drivers for actionable insights  

**Tools Used:**  
`Python`, `NLTK`, `Scikit-learn`, `WordCloud`, `Matplotlib`, `Seaborn`
